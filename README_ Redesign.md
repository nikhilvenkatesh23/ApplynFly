# ApplyNFly Website

Static, mobile-friendly website for Apply n Fly, an overseas education consultancy in Anna Nagar, Chennai. Built with HTML, CSS, JavaScript and Bootstrap; no server-side code or build step is required.

## Updates

- Refreshed the brand styling, responsive navigation and ApplyNFly logo.
- Added study destinations, process steps, FAQs and profile-evaluation/contact forms.
- Added a dedicated shareable evaluation page at `profile-evaluation.html`; the homepage and footer link to it.
- Added SEO metadata, structured data, sitemap and robots file; optimized site images as WebP.
- Added draft Privacy Policy and Terms pages. **Have both reviewed before publishing.**
- Removed unused template pages, images and vendor assets.

## Before publishing

- Replace `YOUR_ACCESS_KEY` in `index.html` with the Web3Forms access key.
- Deploy the Google Apps Script in `docs/apps-script.gs`, configure its spreadsheet, and replace `YOUR_APPS_SCRIPT_WEB_APP_URL` in `assets/js/main.js`. See `docs/apps-script-setup.md`.
- Review the policy and terms drafts against actual data-handling practices and have them reviewed by qualified counsel.
- Add real Facebook, LinkedIn or YouTube URLs in the footer if those profiles are created; their placeholder links are hidden.

Open `index.html` directly or host the files on any static web host.
